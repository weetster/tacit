# 059 — echo-reverse

Output all input lines in reverse order.

## Input

Zero or more lines.

## Output

The same lines, but in reverse order. If the input is empty, output nothing.

## Examples

```
one
two
three
```
→
```
three
two
one
```

```
hello
```
→
```
hello
```

## Constraints

- Number of lines ≤ 100_000.
- Line length ≤ 10_000 characters.
