# 052 — sum-numbers

Sum a list of integers, one per line.

## Input

Any number of lines (zero or more). Each non-blank line contains a single
integer in decimal. Blank lines are skipped.

## Output

A single line: the sum as a decimal integer. If there are no integers, output
`0`.

## Examples

```
1
2
3
4
```
→
```
10
```

```
-5
5
```
→
```
0
```

## Constraints

- Input size ≤ 16 MiB.
- The sum fits in an `i64`.
