# 036 — quicksort

Sort a list of integers using quicksort with a deterministic middle pivot.

## Input

One line of space-separated integers.

## Output

One line: the integers sorted in ascending order, space-separated.

## Examples

```
5 3 8 1 9 2
```
→
```
1 2 3 5 8 9
```

```
4 4 2 4 1
```
→
```
1 2 4 4 4
```

```
7
```
→
```
7
```

## Constraints

- 1 ≤ N ≤ 100_000 elements.
- Values fit in `i64`.
- Input may contain duplicates.
