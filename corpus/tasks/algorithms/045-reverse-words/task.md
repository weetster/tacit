# 045 — reverse-words

Reverse the order of words in a line, preserving single spaces between words.

## Input

A single line of space-separated words.

## Output

A single line: the words in reverse order, joined by single spaces.

## Examples

```
the quick brown fox
```
→
```
fox brown quick the
```

```
hello
```
→
```
hello
```

```
one two three
```
→
```
three two one
```

## Constraints

- Line length ≤ 10_000 characters.
- Words are separated by single spaces (no leading/trailing spaces, no consecutive spaces).
- At least one word is present.
