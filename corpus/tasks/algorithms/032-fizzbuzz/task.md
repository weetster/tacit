# 032 — fizzbuzz

Print the FizzBuzz sequence from 1 to N inclusive, one item per line.

For each integer `i` in `1..=N`:

- If `i` is divisible by 15, print `FizzBuzz`.
- Else if `i` is divisible by 3, print `Fizz`.
- Else if `i` is divisible by 5, print `Buzz`.
- Else print `i` as a decimal integer.

## Input

A single line containing a non-negative integer N (0 ≤ N ≤ 10_000).

## Output

N lines, each terminated by a newline. If N = 0, output nothing.

## Example

```
5
```
→
```
1
2
Fizz
4
Buzz
```
