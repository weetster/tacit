# 001 — sum-to-n

Print the sum 1 + 2 + ... + N.

## Input

A single line containing a non-negative integer N (0 ≤ N ≤ 10^9).

## Output

A single line: the sum, as a decimal integer.

## Examples

```
5
```
→
```
15
```

`N = 0` yields `0` (empty sum).

## Constraints

- N fits in an `i64` / Python `int`.
- The result also fits in an `i64`.
