# 010 — power

Compute B raised to the power E using integer exponentiation.

## Input

Two lines:

1. Base B (integer).
2. Exponent E (non-negative integer).

## Output

A single line: B^E as a decimal integer.

## Examples

```
2
10
```
→
```
1024
```

```
3
0
```
→
```
1
```

```
-2
5
```
→
```
-32
```

## Constraints

- -100 ≤ B ≤ 100.
- 0 ≤ E ≤ 30.
- The result fits in an `i64`.
