# 016 — longest-word

Find the longest word in a line of text. On ties, return the first occurrence.

## Input

A single line of space-separated words. Words contain no spaces. The line is non-empty and contains at least one word.

## Output

A single line: the longest word. On ties, the first occurring longest word.

## Examples

```
the quick brown fox
```
→
```
quick
```

```
cat bat hat
```
→
```
cat
```

```
hello world
```
→
```
hello
```

## Constraints

- Line length ≤ 10_000 characters.
- At least one word is present.
- Words are separated by single spaces.
