# 012 — count-vowels

Count the ASCII vowels in the input.

## Input

All of standard input. May be multi-line.

## Output

A single line: the count of characters that are in the set
`{'a','e','i','o','u','A','E','I','O','U'}`, as a decimal integer.

Only ASCII vowels count. Accented vowels (e.g. `é`) do not.

## Examples

```
hello
```
→
```
2
```

```
The quick brown fox
jumps over the lazy dog
```
→
```
11
```

## Constraints

- Total input ≤ 1 MiB.
