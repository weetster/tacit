# 021 — unique-in-order

Remove consecutive duplicate values from a sequence of integers, preserving
the order of first occurrence in each run.

## Input

A single line containing zero or more space-separated integers.

## Output

A single line containing the deduplicated sequence as space-separated
integers. If the result is empty, output a single empty line.

## Examples

```
1 1 2 3 3 3 2 2 1
```
→
```
1 2 3 2 1
```

- Input length ≤ 100_000 tokens.
- Values fit in `i64`.
