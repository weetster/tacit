# 002 — fibonacci

Print the N-th Fibonacci number, where F(0) = 0 and F(1) = 1.

**Held-out.** Must not appear in primer examples or training material.

## Input

A single line containing a non-negative integer N (0 ≤ N ≤ 90).

## Output

A single line: F(N) as a decimal integer.

## Examples

```
0
```
→
```
0
```

```
10
```
→
```
55
```

## Constraints

- N ≤ 90 guarantees the result fits in an unsigned 64-bit integer.
